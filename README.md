# 🎸 ROCK ANTHEM

> **Heavy Modern Rock • Stadium Anthems**

O **ROCK ANTHEM** é um projeto musical criado com a proposta de unir o peso do **Hard Rock moderno** à energia e à grandiosidade dos grandes **hinos de estádio**.

O projeto foi concebido para transmitir uma identidade forte, cinematográfica e moderna, utilizando elementos visuais inspirados em **palcos, iluminação de shows, guitarras, multidões e grandes performances ao vivo**.

---

## 🎯 Conceito

O conceito do ROCK ANTHEM nasceu da ideia de transformar a experiência de ouvir rock em algo **visual e imersivo**.

A identidade combina:

* 🎸 Guitarras pesadas
* 🥁 Bateria com grande impacto
* 🔥 Energia de palco
* 🏟️ Atmosfera de estádio
* 💜 Iluminação neon
* 🌌 Elementos cinematográficos
* 🎤 Grandes refrões e participação do público

A proposta é criar uma presença digital que represente a mesma energia das músicas: **forte, moderna, intensa e épica**.

---

## 🎨 Identidade Visual

A identidade visual utiliza principalmente tons escuros combinados com **roxo neon e azul neon**, criando contraste entre o peso do rock e uma estética moderna/tecnológica.

### Paleta de cores

| Cor            | HEX       | Utilização            |
| -------------- | --------- | --------------------- |
| Preto profundo | `#050509` | Fundo principal       |
| Roxo escuro    | `#160B2B` | Fundos e gradientes   |
| Roxo neon      | `#7B2CFF` | Destaques e botões    |
| Azul neon      | `#00C8FF` | Detalhes e iluminação |
| Azul escuro    | `#102A43` | Elementos secundários |
| Branco         | `#F5F5F7` | Textos principais     |
| Cinza          | `#8A8A96` | Textos secundários    |
| Roxo claro     | `#B56CFF` | Brilhos e efeitos     |

### Gradiente principal

```css
linear-gradient(135deg, #050509, #160B2B, #102A43);
```

## 🔤 Tipografia

A tipografia deve transmitir uma aparência **moderna, forte e tecnológica**, mantendo boa legibilidade.

### Fonte principal

**Montserrat**

Utilizada para:

* Títulos
* Botões
* Nome ROCK ANTHEM
* Elementos de destaque

### Fonte secundária

**Inter**

Utilizada para:

* Textos
* Descrições
* Informações secundárias
* Navegação

A combinação cria contraste entre títulos mais marcantes e textos limpos e fáceis de ler.

## 🌐 Conceito do Site

O site foi concebido como uma **landing page simples e direta**, apresentando o projeto musical sem excesso de elementos.

A estrutura planejada inclui:

Apresentação principal do ROCK ANTHEM com:

* Nome do projeto
* Frase de impacto
* Imagem ou cenário de palco
* Botão para ouvir as músicas

### Lançamentos

Área destinada às músicas e futuros lançamentos do projeto.

### Sobre o projeto

Uma breve apresentação da proposta musical e artística do ROCK ANTHEM.

### Redes sociais

Links para as plataformas onde o projeto estará presente.
